# app

The RedwoodSDK Worker. It serves the HTML app and forwards chat traffic to the
`agents` package over the `AGENT` service binding.

- Worker name: `app-starter`
- Dev URL: <http://localhost:5173>
- Entry point: `src/worker.tsx`

This package is one half of a pnpm + Turborepo monorepo. The root docs cover
setup, and this one covers only what is specific to the app:

- [`../../README.md`](../../README.md) — setup, architecture, deploy order.
- [`../../AGENTS.md`](../../AGENTS.md) — repo-wide commands.
- [`AGENTS.md`](AGENTS.md) — where this package's docs live.

## Commands

Run these from the repo root. They start both Workers and apply the environment
guard:

```sh
pnpm dev     # app on 5173, agents on 5174
pnpm build   # builds into dist/
pnpm check   # typechecks this package and agents
pnpm gen     # regenerates worker-configuration.d.ts
```

Running this package's own `dev` script serves the app alone, so `AGENT`
stays unresolved unless the agents Worker is already running.

## Notable files

- `src/worker.tsx` — the route map. Mounts `/api/agent/:conversationId`.
- `src/app/` — pages, the HTML document, and shared response headers.
- `src/app/styles.css` — global Tailwind v4 stylesheet and `@theme` design
  tokens. `document.tsx` links it as `./styles.css?url`.
- `wrangler.jsonc` — declares the `AGENT` service binding.
- `worker-configuration.d.ts` — generated by `pnpm gen`. Do not edit by hand.
- `vite.config.mts` — `cloudflare()` before `redwood()`, then `tailwindcss()`.
  Keep that order.
